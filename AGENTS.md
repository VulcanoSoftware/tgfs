# TGFS — Base44 Dev Environment

## Architecture
- **Frontend** (`tgfs-gh-pages/`): Next.js 15 app (Turbopack dev server) on port 3000.
  Serves the landing page, config generator, getting-started docs, and Telegram mini-app.
  The production build uses `output: "export"` with `basePath: "/tgfs"`; in dev, `NEXT_PUBLIC_BASE_PATH`
  is set to empty so the preview serves at `/`.
- **Backend** (`main.py` + `tgfs/`): Python 3.13 FastAPI app on port 1900. Connects to Telegram
  via Pyrogram/Telethon and serves WebDAV + manager API. Requires real Telegram credentials.

## Running
```
docker compose -f docker-compose.base44.yml up -d
```
- Frontend: http://localhost:3000
- Backend API: http://localhost:1900

## Backend Config
The backend reads a YAML config generated by `scripts/dev-config.sh` from environment variables
(stored in `/run/base44/app.env`, overriding `.env.base44-defaults`). Required secrets:
- `TGFS_API_ID` / `TGFS_API_HASH` — from https://my.telegram.org/apps
- `TGFS_BOT_TOKEN` — from @BotFather; bot must be admin in the target channel
- `TGFS_CHANNEL_ID` — Telegram private channel ID
- `TGFS_JWT_SECRET` — auto-generated; replace with your own for production
- `TGFS_GITHUB_REPO` / `TGFS_GITHUB_TOKEN` — GitHub repo for metadata storage
  (defaults to the public `tgfs-demo/tgfs-demo` repo; replace with your own)

The metadata type is `github_repo` (not `pinned_message`) because pinned messages require a
Telegram account session (interactive login), which can't be automated in compose.

## Dev Notes
- `lru-dict` needs `gcc` to build its C extension; the compose installs `build-essential` on first run.
- Use `python -m poetry` (not `poetry`) in the api service — the `python_packages` volume preserves
  Python code but not the CLI entry point binary across container recreates.
- Frontend healthcheck uses `127.0.0.1` (not `localhost`) because Next.js dev server binds IPv4 only;
  `localhost` resolves to `::1` (IPv6) in Alpine, causing "Connection refused".
- `allowedDevOrigins` in `next.config.ts` covers the Base44 preview origin for HMR/dev assets.
